v11.12.1: убран тумблер "Спин только стоя"

По просьбе удалён тумблер "Спин только стоя" из вкладки ТАНЕЦ, а также
проверка движения в самом спине:

  - if G.BS.SpinOnlyStill and hum.MoveDirection.Magnitude > 0.1 then return end
  - G.BS.SpinOnlyStill = nil   (в настройках)
  - G.BS.SpinOnlyStill = false  (из миграции CfgV)

Теперь спин крутит модель и на ходу, и стоя: движение не мешает,
персонаж просто вращается вокруг корня (AutoRotate при этом всё равно
ставится в false, иначе гуманоид доворачивал бы модель по вектору
движения и вращения не было бы видно).

CfgV не менялся: удаление настройки ничего не ломает, старые значения
игнорируются. Версия помечена v11.12.1.
Проверено: luac -p чисто, luacheck 0 ошибок (5 старых безобидных).
