v11.15.1: убран тумблер «ПОВ: камера доворачивается»

По просьбе удалён тумблер из вкладки AIM:
  AI.CreateToggle({ Name = "Камера доворачивается (аимлок)", ... })

Аимлок теперь ВСЕГДА доводит камеру:
  G.BS.AimLockTurn = true  (задаётся при старте, без сохранения флага)

Если понадобится тихий аим без поворота камеры (только подмена патрона):
  getgenv().BS.AimLockTurn = false

Круг аима (ПОВ) остался без изменений: ползунок «Радиус круга (FOV)»
и тумблер «Показывать круг аима».

Версия помечена v11.15.1.
Проверено: luac -p чисто, luacheck 0 ошибок (5 старых безобидных).
