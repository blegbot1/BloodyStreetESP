v11.14: танцы через EmotePlay, аим без ЛКМ, ПОВ и панель GUI под HUD

1) ТАНЦЫ ИГРАЕМ НАСТОЯЩИМ РЕМОУТОМ ИГРЫ.
Из лога видно, что танец включается так:
  game:GetService("ReplicatedStorage").BloodyStreet.Remotes.EmotePlay:FireServer("emote_dance")
Значит, для танца НЕ НУЖНЫ ID анимаций: игра принимает имя эмоута.
 - в список танцев добавлены ЭМОУТЫ ПО ИМЕНИ (dance.addEmote), первым
   всегда идёт emote_dance - он выбран по умолчанию, даже если сканер
   ничего не нашёл;
 - при включении "Танцевать" посылается EmotePlay:FireServer("emote_dance");
 - танец повторяется каждые 2.5 с (danceTick) - игра отменяет эмоут при
   движении, повтор возвращает его на ходу;
 - имена эмоутов долетают и из EmotePlay в хуке __namecall, и из
   EmoteSetSlots - они автоматически добавляются в список;
 - в подписи списка эмоуты помечены "эмоут <имя>", анимации - "<имя> …ID".

2) АИМЛОК БОЛЬШЕ НЕ ЗАВИСИТ ОТ КЛИЕНТ-АИМА.
Раньше bulletPreShot считался только при G.BS.BulletSwap:
  if not G.BS.BulletSwap then bulletPreShot = nil return end
Поэтому при выключенной подмене патрона аимлоку нечего было вести -
жалоба "аим не целится". Теперь условие:
  if not (G.BS.BulletSwap or G.BS.AimLock) then ...
и аимлок сам вызывает computeBulletPreShot, если тот ещё не считался.

3) УБРАН FLAG У AIM-ТУМБЛЕРОВ.
Rayfield ConfigurationSaving восстанавливает сохранённые значения ПОСЛЕ
старта и вызывает колбэки. Из-за этого аимлок мог остаться выключенным,
а "Аим пока держишь пушку" - включённым (старые сохранения). Теперь у
"Клиент айм", "Аимлок", "ПОВ", "Аим пока держишь пушку" нет Flag: они
всегда стартуют с дефолтов движка.

4) ПОВ (ПОВОРОТ КАМЕРЫ).
Новый тумблер "ПОВ: камера доворачивается" (G.BS.AimLockTurn):
  true  - камера ведётся на цель (как раньше);
  false - камера остаётся твоей, патрон всё равно летит в цель.
Аимлок теперь вешается на приоритет Last - 1 (1999), а не Camera + 1:
если игра или другой скрипт правит камеру позже, наш доворот не
затирается.

5) ОРУЖИЕ В РУКАХ ОПРЕДЕЛЯЕТСЯ ШИРЕ.
Кроме "gun" в названии теперь принимаются shot/sniper/pistol/revolver/
rifle/musket, а также Tool с Muzzle или атрибутом Variant.

6) БЫСТРАЯ ПАНЕЛЬ GUI ПОД HUD (по скриншоту - "тут надо добавить гуи").
Под строкой HUD появилась панель с кнопками-переключателями:
  АИМ | АИМЛОК | ПОВ | ТАНЕЦ | СПИН | ТАНЕЦ → | МЕНЮ
Зелёная кнопка = включено, тёмная = выключено. "ТАНЕЦ →" листает танцы,
"МЕНЮ" открывает/закрывает окно Rayfield. Состояние подсветки
обновляется каждые 0.25 с, поэтому видно переключения и из меню.

7) СПИН: убрана подпись "(как в EliteHub)" у ползунка скорости -
теперь просто "Скорость спина, °/с". Дефолт скорости 50.
