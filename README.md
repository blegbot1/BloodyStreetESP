# Bloody Street ESP + Aimbot

Версия **v6.7**. Проверено: `luac -p` чисто, `luacheck` — 0 ошибок.

## Роли

Только атрибут `player.Role` (его ставит сервер каждому игроку, он
реплицируется всем) + роли из ремоутов + вывод по счётчикам раунда.

Все догадки по вещам удалены — они ломали правдивость:
- «пустой инвентарь = вампир» → красные все (оружия ещё не выдано)
- «в персонаже есть слово blood» → красные все, потому что `BloodTester`
  это кровотест **хантера**

## Прицел (кружок FOV)

Главная секция вкладки **AIM → «Круг прицела»**:
- живой абзац: радиус захвата + оба цвета кружка (`#RRGGBB`)
- переключатель «Показывать кружок» (рисуется всегда, при выключенном
  аиме — приглушённый)
- переключатель «Менять цвет при захвате игрока»
- два пикера: цвет свободного состояния и цвет захвата

## Главный цвет (RGB)

Первая секция вкладки **ESP**: ползунки **R / G / B**, поле **HEX**
(`FF3755` или `F35`) и список «Что красить этим цветом»:

1. Прицел: свободный
2. Прицел: захват цели
3. ESP вампиров
4. ESP хантеров
5. ESP игроков
6. Метка цели

Квадрата-превью на экране нет — цвет и так видно на кружке и на ESP,
а точные цифры показывает живой абзац «Текущий цвет».

## Аимбот — как в ELITE HUB

- **один движок: камера.** Выбора «Мышь»/«Персонаж» нет
- упреждения (lead) нет — доворот идёт ровно в точку прицеливания
- FOV вокруг центра экрана
- рейкаст видимости исключает собственный персонаж
- замок на цель: запертая цель не отваливается за экран
- часть тела цепочкой `Head → UpperTorso → HumanoidRootPart`
- чувствительность `0` = мгновенный доворот камеры

## Запуск

Вставить `BloodyStreetESP.lua` в исполнитель целиком.
