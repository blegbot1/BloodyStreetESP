# Bloody Street ESP + клиент-айм

Версия **v9.2**. Проверено: `luac -p` — чисто, `luacheck` — 0 ошибок.

## Что нового

### v9.2
- **Тело игрока теперь красится по роли.** `Highlight` создавался с
  `FillTransparency = 1` — заливки не видно, — а цвет роли писался
  **только** в этот невидимый `FillColor`. `OutlineColor`, то есть то,
  что реально видно, не менялся вовсе и оставался белым. Поэтому по роли
  красились только коробка и текст. Теперь красятся и контур, и заливка.
- Прозрачность заливки настраивается на ходу:
  `getgenv().BS.FillTransparency = 0.4` (0 — залито полностью,
  1 — только контур).

### v9.1
- **Выстрел через всю карту.** Дальность подмены была 300 студов — дальше
  цель вообще не выбиралась. Теперь `G.BS.AimMaxDist = 0` (**без
  ограничения**). Старое значение 300 мигрируется в 0 автоматически.
- **Прострел стен теперь всегда ВКЛ.** Переключателя в GUI нет, а
  сохранённое старое `false` только отбрасывало цели за стеной.
- **Длина вектора выстрела = расстоянию до цели** (лимит поднят до 20 000),
  чтобы пуля долетала и через всю карту.
- **Цель ищется шире.** «Под прицелом» — теперь ~треть экрана от центра
  (раньше жёсткие 220 px: дальний враг занимает пару пикселей и в узкий
  круг не попадал). Среди тех, кто под прицелом, берётся **ближайший к
  центру экрана**, а не ближайший по расстоянию.

### v9.0
- **Роли теперь ищутся по ЗНАЧЕНИЮ, а не по имени поля.** Раньше
  проверялся только фиксированный список имён атрибутов (`Role`, `Team`, …).
  Если игра называла атрибут иначе — роль не находилась **ни у кого**, и ESP
  не красил ни вампиров, ни хантеров. Теперь просматриваются все атрибуты
  игрока и персонажа, а также `StringValue` / `BoolValue` в персонаже:
  что похоже на роль — то и роль. Какое поле сработало, видно в сканере.
- **Пуля больше не «пролетает мимо».** В аргумент выстрела клался либо
  единичный вектор, либо **абсолютная** позиция цели. Если игра берёт
  дальность из длины этого вектора, длина 1 = 1 студ → трассер рисуется,
  а попадания нет. Теперь направление сохраняет длину и она не меньше
  расстояния до цели.
- **Цель выбирается по прицелу.** Раньше всегда брался ближайший по
  расстоянию враг, поэтому выстрел в дальнего уходил в ближнего сбоку.
  Теперь приоритет — тот, кто под прицелом (в радиусе 220 px от центра),
  и только если под прицелом пусто — ближайший.
- **Опережение цели (по умолчанию выключено).** Если пуля летит заметное
  время, можно включить в консоли: `getgenv().BS.AimLead = 0.15`
  (сколько секунд вперёд целиться).
- **Диагностика патрона печатает ЗНАЧЕНИЯ аргументов**, а не только типы —
  по ней видно, какой аргумент за что отвечает.
- **Сканер печатает роли всех игроков** и все поля, откуда их можно взять.

### v8.7 (главное — починка падений игры)

**Починена причина, из-за которой v8.6 роняла игру.** Скрипт вешал хук на
`game.__namecall` так:

```lua
local old = hookmetamethod(game, "__namecall", function(self, ...)
    return old(self, ...)   -- <-- здесь old ГЛОБАЛЬНАЯ (nil)!
end)
```

В Lua область видимости `local old` начинается **после** объявления. Поэтому
внутри функции справа `old` — не та переменная, что объявляется, а глобальная
(равная `nil`). Итог: на **каждый** вызов через `:` в игре (`FindFirstChild`,
`FireServer`, `wait`, ...) хук делал `attempt to call a nil value`. Отсюда сыпались
`GarlicController`, `ControlModule`, `CameraModule`, `InputLock`, `HotbarController`.

Что сделано:
- **forward-декларация** (`local old` + отдельное присвоение) вместо
  `local old = ...`;
- оригинал `__namecall` берётся из **сырой метатаблицы** (`getrawmetatable`);
- если оригинала нет — хук **не ставится вообще** (лучше без прострела, чем
  сломанная игра);
- `G.BS_Stop` корректно снимает хук;
- один общий хук `__namecall` обслуживает прострел, стамину и защиту от урона
  (отдельные `hookmetamethod(remote, "FireServer")` в этом исполнителе не
  работают — он принимает только имена метаметодов).

## Вкладка ESP

- 3D-коробки вокруг игроков;
- ник, дистанция, HP;
- цвета по ролям: вампир / хантер / игрок;
- Highlight + BillboardGui;
- роли только из надёжных источников: атрибут `player.Role`, роли из ремоутов
  (`RoleAssigned`, `RoleScan`, `RoleSeer`, `RoleToggle`), счётчики раунда.
  Догадки «по вещам» удалены — они ломали правдивость.

## Вкладка AIM

Только клиент-айм (подмена патрона) + прострел стен + диагностика.
Аимбота с доводкой камеры, круга прицела и бинда **нет**.

- **Клиент айм** — по умолчанию **ВКЛ**: аргументы `FireWeapon` подменяются так,
  чтобы пуля шла в выбранного противника (работает и через стены);
- прострел включён; дистанция подмены — 300, радиус метки — 160 px;
- **Диагностика патрона** — печатает в консоль сигнатуру `FireWeapon`
  (`[BS BULLET] подмена работает / сигнатура не распознана`).

## Защита от урона NPC / стамина

Оба выключены по умолчанию и живут в едином хуке `__namecall`
(`UseEnergy` — стамина, `TakeDamage` — урон).

## Запуск

Репозиторий **публичный**, поэтому достаточно одной строки — скрипт всегда
подтягивает свежую версию с GitHub:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/blegbot1/BloodyStreetESP/main/BloodyStreetESP.lua", true))()
```

Либо скопировать `BloodyStreetESP.lua` в редактор исполнителя целиком —
результат тот же.

`loader.lua` делает то же самое плюс защита от двойного запуска в течение
5 секунд.

Остановить скрипт: `G.BS_Stop()` (снимает хук `__namecall`, отключает все
коннекты и удаляет GUI/коробки).
